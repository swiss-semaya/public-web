# public-web

Published output only. Everything here is a build artefact — nothing in this
repository is edited by hand.

| File | What it is |
|---|---|
| `index.html` | **ONZE** — a daily revision app (French, German, English, maths). One file, no dependencies, no network calls; works entirely offline. |
| `manifest.webmanifest`, `sw.js` | What turns the page into an installable app on a phone. Generated by the same build. |
| `icon-180/192/512.png` | Home-screen icons, generated by `icone.py` in the source repository. |
| `.nojekyll` | Serves the files as-is, without Jekyll processing. |

## Where the source lives

ONZE is built from `carnet/onze.html` in a separate private repository, by
running `build.py` there. Never edit `index.html` directly — the next build
overwrites it.

That build script produces this public copy with the first names removed: the
header, the `<meta description>`, the error message and the `localStorage` key
are all anonymised. It refuses to write the file if a name survives.

## How it works

Plain JavaScript in a single file: a five-box spaced-repetition engine over
66 topics and 599 written exercises, backed by 34 procedural generators so the
supply of exercises never runs out. Topics are pinned to the school calendar —
the day before a test, the whole session converges on what is being examined.
Progress is kept in `localStorage`, so it is per-browser and never leaves the
device.

## Installing it on a phone

Open the published address in Safari or Chrome, then *Share → Add to Home
Screen*. The service worker keeps the app working offline, but serves
**network-first** for the page itself: online, you always get the newest build;
offline, you get the last one that loaded. A cached copy must never be able to
pin a pupil to an old version.
